Solo Overhaul is a rework of SPT's live Tarkov-inherited systems to better fit a singleplayer experience. Features like insurance, the flea market, hideout timers and many more exist in the base game as MMO mechanics designed around a live economy, player interaction and daily logins.

Insurance removal implementation is based on DanW's [Hardcore Rules](https://forge.sp-tarkov.com/mod/784/hardcore-rules) mod.
